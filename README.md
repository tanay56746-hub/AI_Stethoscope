An end-to-end deep learning research system for simultaneous cardio-pulmonary acoustic analysis from stethoscope audio recordings. The framework couples a shared convolutional neural network with 397 handcrafted physical acoustic features and 2048-dimensional PANNs AudioSet foundation embeddings, serving concurrent cardiac and respiratory predictions through an interactive biomedical demonstration dashboard.

---

## System Architecture

```
                                  [ Audio WAV Input ]
                                          │
                                 Standard Preprocessing
                        (20 Hz HP Filter, 16 kHz Sinc Resampling,
                           Peak Normalize 0.95, 5.0s Window)
                                          │
        ┌─────────────────────────────────┼─────────────────────────────────┐
        │                                 │                                 │
  Log-Mel Spectrogram             Physical Features                  PANNs AudioSet
   (128 × 313 frames)              (397 Dimensions)                (2048 Dimensions)
        │                                 │                                 │
   Shared 2D CNN                          │                         Dense Projection
  Feature Extractor                       │                          (2048 → 128-D)
        │                                 │                                 │
        └─────────────────────────────────┼─────────────────────────────────┘
                                          │
                                Multi-Task Concatenation
                                  & Shared Dense Latent
                                          │
             ┌────────────────────────────┼────────────────────────────┐
             │                            │                            │
      [ Heart Sound Head ]      [ Lung Acoustic Head ]       [ Lung Disease Head ]
       Normal / Abnormal           Normal / Crackle /           Normal / Asthma /
       (PhysioNet 2016)          Wheeze / Crackle+Wheeze              Other
                                      (ICBHI 2017)                   (Kaggle)
```

## Key Features

1. **Multi-Task Auscultation Backbone**:
   - Single unified network processing 5-second acoustic recordings to simultaneously evaluate cardiac rhythm abnormalities and pulmonary adventitious sounds.
   - Mitigates task-specific overfitting through shared representation learning across PhysioNet 2016, ICBHI 2017, and Kaggle respiratory corpora.

2. **Tri-Modal Feature Fusion**:
   - **Time-Frequency**: 128 Mel-frequency bins across 313 temporal frames preserving cardiac (20–800 Hz) and respiratory (100–2000 Hz) acoustic bands.
   - **Domain-Specific Acoustics**: 397 handcrafted physical features (spectral centroid, spread, roll-off, flux, zero-crossing rate, MFCCs, and temporal energy dynamics).
   - **General Audio Foundation**: 2048-dimensional frozen representation from PANNs (Pretrained Audio Neural Networks) CNN14, projected into a compact 128-dimensional latent vector.

3. **Biomedical Demonstration UI**:
   - Clean, laboratory-styled light clinical dashboard built with React 19 and Vite.
   - Drag-and-drop WAV upload with preloaded clinical sample (`b0032.wav`).
   - Native HTML5 Canvas renderers for audio waveform and 20 Hz – 2000 Hz Log-Mel spectrogram heatmap.
   - Real-time probability outputs with class confidence bars.
   - Interactive 7-stage architectural pipeline walkthrough and collapsible model technical specifications.

---

## Important Distinction

- **LIVE DEMONSTRATION**: Real-time probability outputs generated by the trained multitask model for the uploaded audio. These are demonstration outputs for research presentation and are not themselves evidence of model accuracy or clinical diagnosis.
- **MODEL BENCHMARK RESULTS**: Formal model accuracy and generalization metrics are established separately via rigorous held-out test-set evaluations across the benchmark datasets.

## Quickstart Guide

### 1. Prerequisites
- Python 3.10+
- Node.js 18+ (for frontend development)
- PyTorch 2.0+

Install Python dependencies:
```bash
pip install torch torchaudio numpy librosa soundfile scipy
```

### 2. PANNs CNN14 Pretrained Weights
Download the official pretrained weights (`Cnn14_mAP=0.431.pth`, ~312 MB) from Zenodo into `pretrained_weights/`:
- **Direct Link**: [Zenodo PANNs Cnn14 Checkpoint](https://zenodo.org/record/3987831/files/Cnn14_mAP=0.431.pth)
- **Path**: `pretrained_weights/Cnn14_mAP=0.431.pth`

*(The final trained multi-task checkpoint is already included in `experiments/multitask_ablations/cnn_physical_panns/checkpoints/best_checkpoint.pt`).*

---

### 3. Command-Line Audio Inference

Run offline prediction on any standard WAV audio file:

```bash
python scripts/predict_audio.py --audio "datasets/Heart/Raw/training/training-b/b0032.wav"
```

### 4. Running the Demonstration Web UI

#### Unified Server (Recommended)
Start the Python demonstration server (automatically serves the built frontend from `frontend/dist`):

```bash
python scripts/demo_server.py --port 8000
```

Open your browser at:
```
http://127.0.0.1:8000
```

#### Frontend Development Mode
To develop or customize React components with hot-module replacement:

1. Start the API server:
   ```bash
   python scripts/demo_server.py --port 8000
   ```
2. In a separate terminal, launch the Vite dev server:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
3. Open `http://127.0.0.1:5173`.

## Technical Specifications

| Parameter | Specification |
|:---|:---|
| **Audio Format** | Single-channel 16-bit PCM WAV |
| **Analysis Window** | 5.0 seconds (80,000 samples @ 16 kHz) |
| **Bandpass Filtering** | 4th-order Butterworth High-pass (20 Hz cutoff) |
| **Resampling** | Band-limited sinc interpolation (`soxr_vhq`) |
| **Spectrogram** | 128 Mel frequency bins × 313 temporal frames |
| **Physical Features** | 397 dimensions (spectral, temporal, energy dynamics) |
| **AudioSet Embedding** | 2048 dimensions (PANNs CNN14 backbone) |
| **Latent Projection** | 2048 → 128 dimensions |
| **Optimizer** | AdamW |
| **Inference Latency** | ~0.65 seconds on CPU |
